# MSN Messenger Clone (Java Sockets)

Projeto de estudo em Java focado em comunicação em rede via TCP Sockets, Threads e interface gráfica.

## 🎯 Objetivos
- [x] Inicialização do repositório
- [x] Servidor de chat multithreaded (TCP)
- [x] Cliente em modo terminal
- [ ] Interface gráfica (Swing) no estilo MSN
- [ ] Recursos clássicos (Chamar atenção, sons, status)

## 🛠️ Tecnologias
- Java 17+
- Sockets (`java.net`)
- Concorrência (`java.util.concurrent` / Threads)
- Swing (GUI).
